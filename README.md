# Haneen Elmahdy Portfolio

A static, GitHub Pages-ready portfolio with no external dependencies.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `haneen-portfolio`.
2. Upload `index.html` and `Haneen_Elmahdy_CV.pdf` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public portfolio URL after deployment.

## Update content

- Replace résumé file: keep the filename `Haneen_Elmahdy_CV.pdf`, or update the links in `index.html`.
- Update project links only when repositories are publicly accessible.
- Keep manuscript labels accurate (`Submitted`, `Under review`, `Accepted`, or `Published`).
- Update dates and metrics only when supported by records.
